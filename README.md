QNA About React

Q:What is JSX, and why is it used in React?

Ans:JSX is a syntax that allows us to write HTML-like code inside JavaScript. It is used in React to create the user interface easily.

Q:What is the difference between props and state?

Ans:Props are used to pass data from a parent component to a child component. State is used to store and manage data inside a component.

Q:What does the useState hook do, and where did you use it in this project?

Ans:The useState hook is used to create and manage state in a React component. In this project, I used it to manage the selected technologies in the stack.

Q:What does the useEffect hook do, and why did you need it to load the JSON data?

Ans:The useEffect hook is used to perform side effects in a component. In this project, I used it to load the technology data from the JSON file.

Q:Why does every item in a .map() list need a unique key prop?

Ans:A unique key helps React identify each item in a list. It helps React update the list efficiently when something changes.

Q:What is conditional rendering? Show one place you used it.

Ans:Conditional rendering means showing different content based on a condition. In this project, I used it to show an empty stack message when no technology is selected.

Q:How do you pass data from a parent component to a child component, and how does a child send something back to the parent?

Ans:We pass data from a parent to a child using props. A child can send data back to the parent by calling a function that the parent passes through props.
